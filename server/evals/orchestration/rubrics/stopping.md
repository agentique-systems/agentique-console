# stopping

**Question:** Did the run stop at the right time — neither premature completion nor endless polish?

- **5** — Completion declared when criteria had independent evidence; remaining ideas explicitly triaged (below-value: recorded; beyond-scope: proposed); every extra iteration named its gap first.
- **3** — Sound stop with a thin completion account, or one unjustified extra loop.
- **1** — Declared done with known defects unaccounted, or polished indefinitely without naming what each pass closed.
