# marginal-agent-value

**Question:** Did every additional agent contribute marginal information, quality, or capacity beyond those already working?

- **5** — Each seat justified (independent uncertainty, different solution family, independent evidence, real throughput); no duplicated framing; nothing below delegation overhead.
- **3** — Mostly justified with one redundant or under-loaded seat.
- **1** — Fleets spawned for show; agents duplicating one another; outputs that influenced no decision.
