# pattern-selection

**Question:** Did the chosen coordination pattern(s) fit the work's real shape?

- **5** — Pattern matches dependency structure (serial→pipeline, unknown→hub, independent-N→map_reduce, contested→debate); composition across sessions where one pattern could not express the strategy.
- **3** — Workable but ill-fitting choice that added friction without failure.
- **1** — Pattern actively fought the work (e.g. rigid pipeline for evolving scope) and the orchestrator did not adapt.
