# question-quality

**Question:** Did each question to the operator reduce consequential uncertainty the system could not resolve better itself?

- **5** — Every question was material, batched, information-dense, with a recommendation; answers visibly changed the work; nothing asked that the repo/an experiment could answer.
- **3** — Mostly useful questions with some redundancy or missing recommendations.
- **1** — Questions the codebase already answered, unbatched trickle, or answers ignored after asking.
