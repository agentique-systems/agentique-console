# failure-handling

**Question:** When an agent failed, did the run degrade loudly and recoverably?

- **5** — Failure escalated; work preserved (archived/salvaged); recovery decision explicit (retry/reassign/close); operator informed with an honest account.
- **3** — Handled, with some silent loss or an unexplained retry.
- **1** — Failure swallowed; work destroyed; operator discovered it themselves.
