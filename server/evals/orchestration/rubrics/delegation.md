# delegation

**Question:** Were the right specialists commissioned with briefs that carried the needed context and success criteria?

- **5** — Profile/model fits each job; briefings carry the spec, constraints, and expected evidence; ownership boundaries clean; no capability mismatch.
- **3** — Sound delegation with minor mismatches or thin briefs that cost a round trip.
- **1** — Wrong specialist for the job, context withheld, or work done that nobody needed.
